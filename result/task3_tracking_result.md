## 检测方法（v6.4：RM_Buff_Tracker_GUT 架构 + R 盲窗冻结）

参考实现：github.com/DH13768095744/RM_Buff_Tracker_GUT（桂林理工大学-群星战队，纯传统视觉）。核心原则（v6.4 新增，针对本素材 R 脉冲可见率仅 ~52% 的特点）：

> **R 没有实测 → 一切以 R 为锚的操作冻结**：不做双圆遮挡、不做片段关联、不更新槽位、不重算点亮状态。槽位框、点亮状态、目标身份原样保持，R 重现即恢复；盲窗超过 45 帧才释放目标并重新初始化。此前的版本在 R 外推期间继续错误重匹配，快速平移镜头下 R 外推漂移可达 350px，把目标框拖到中心辐条/流水灯上。

每帧流程：

1. **掩膜**：HSV `H∈[0,17], S≥55, V≥80` + 3×3 开运算（原始掩膜）；另做 5×5 膨胀掩膜仅用于扇叶片段发现。R 字形签名与 inner_density 判据必须在原始掩膜上（实测全掩膜膨胀使 R 检出率 43%→1%）。
2. **R 标**：字形签名（半径 11~14px、面积 215~325px²、圆形度 0.33~0.62、填充率 0.42~0.75、同尺寸孤立）+ 单候选累积；不可见时按**场景位移中位数**外推（大结构逐帧位移 = 相机运动，比 R 自身速度可靠），重现后恢复。
3. **双圆遮挡（仓库核心，仅 R 实测时执行）**：以 R 为圆心，内圆 0.73×radius 实心涂黑抹掉 R 与流水灯，外圆 1.4×radius 空心涂黑隔断外部光源。外推 R 有误差，涂错位置会粉碎真片段，故盲窗期间不做。
4. **扇叶槽位（仓库核心）**：5 个槽位 = 首帧击打框绕 R 旋转 72°×i。帧间关联 = 上一帧槽位框平移 ΔR 后与环带内片段做 IoU（>0.02，所有匹配更新框并集；槽位框尺寸钳制在初始值的 0.35~1.8 倍防误匹配撑大）。片段径向判据收紧为 **0.5×radius < 内沿 < 1.5×radius + 20px**（排除 R 旁小亮块）。
5. **点亮判定**（四道门，全部通过才点亮）：
   - **inner_density 滞回**：槽位中心 0.25×短边圆内占比，进 0.13 / 出 0.09（点亮双环 ≈0.24，未点亮单环 ≈0.07）；
   - **环峰值覆盖 ≥0.35**：在 0.25~1.15×槽位半径上扫描 8 扇区覆盖取峰值。双环靶标实测 0.75~1.0，实心长条/箭头串 ≤0.31；
   - **距离门**：到 R ≤ 1.5×radius+30px（排除底部灯等远距环状干扰）；
   - **槽位中心径向下限 ≥0.55×radius**（v6.4 新增）：实测真靶标中心 p10=0.65×radius，R 旁小方块/箭头串中部 <0.55×radius。
6. **首次初始化自动化**：R 锁定后，在距 R **130~320px**（真实风车半径 170~230px；下限排除辐条/流水灯簇 ~102px，上限排除画面级杂块）的片段中找"面积达标 + inner 点亮 + 箭头串指向"者（箭头串检测：圆点 3.5~12px 贪心链化 + 共线校验——条带检测仅 32% 帧可用，故只用于初始化播种，不作点亮硬门限），跨帧稳定 ≥3 次才建立扇叶表。**重初始化半径必须在上次稳定半径的 [0.65,1.55] 倍内**（实测 task_3 f540 曾把辐条当扇叶配出 radius=102 vs 真实 213、task_4 f16 曾把画面底部杂块当 R 配出 640，均导致半视频错位）。
7. **目标选择与身份**：有效目标 = 点亮槽位；已选槽位保持身份直到连续 15 帧（0.5s）不点亮才切换（防乒乓）；切换/重选分配新 ID 并记录事件；R 盲窗 >45 帧释放重初始化。**R 重现（盲窗 ≥3 帧）后重验证全部槽位径向门限**，不合格的槽位清空重播种，消除错误锚定残留。

## 锁定、丢失与重选规则

- **R 盲窗冻结**：R 非实测（estimated/丢失）期间槽位整体冻结，不关联、不更新、不重算点亮；显示保持最后状态，连续 3 帧后诚实标注 `LOST`（身份保留在冻结位置），>45 帧释放并重新初始化。R 外推仅用于 R 标自身的显示跟随，不参与任何几何判定。
- **击打后切换**：当前目标连续 15 帧非点亮且存在其他点亮槽位 → 切换到 inner 最高者，分配新 ID 并记录事件。
- **持续丢失**：超过 45 帧（1.5s）释放身份，重新满足初始化条件后重选。任何有实测点亮证据的帧都会清零丢失计数（防止跨盲窗累计误触发释放）。
- **同时双目标（task_4）**：只有当前目标熄灭/丢失才可能切换；另一个点亮目标只标注为候选（青色 `ID n`），**不夺走已选身份**。

## 已知失败情况与残留问题

1. **R 盲窗期间显示冻结**：R 脉冲不可见（task_4 占 38% 帧）且槽位无法验证时，目标框停在冻结位置并转为 LOST。快速平移镜头下 R 外推标记可能偏离真实 R 字母（仅影响 R 标显示，不参与判定），R 重现即恢复。
2. **重初始化窗口**：R 盲窗 >45 帧后重新初始化需要 R 字形 + 击打框同时可见且稳定 3 帧（task_3 f508~562、f639~643），期间为 searching——诚实状态，不产生误锁。
3. **点亮计数偶发虚高**：task_4 有 48 帧（2.7%）n_lit≥3（实际最多 2 个真目标），为辐条片段短暂通过点亮门限所致；实测该窗口内选中身份稳定未被夺走，仅影响统计显示，不影响跟踪。
4. **角度仅用于显示**：本任务不要求角速度拟合，`th` 为当前帧的相对角度显示值，不含预测。

## 历史：形态学 A/B 实验（博客做法：膨胀 + 闭运算 + 通道相减）

> 以下为早期（簇几何架构）上的对照实验存档；现行 v6.4 架构下保留的形态学结论：3×3 开运算进主掩膜、5×5 膨胀仅用于片段发现、R 签名与 inner_density 判据必须用原始掩膜。

依据两篇风车识别文章（CSDN RM2023、hejiangda RM19）与 RM 社区《一种RM2024能量机关的识别与角度拟合方法》的推荐，曾做四组对照实验（数据驱动取舍）：

| 方案 | task_3 detected | task_4 detected | 结论 |
|---|---|---|---|
| 基线 | 51.9% | 52.7% | — |
| 双源并集 | 48.4% ↓ | 58.1% ↑ / 切换 30→23 | t3 受损：密集场景合并簇引入抖动 |
| 合并候选仅补空 | 51.9%（=基线） | 52.7%（=基线） | 无效：raw 掩膜下总有候选 |
| 补救关联 | 45.1% ↓↓ | 32.9% ↓↓ | 证伪：合并 blob 质心是坏的位置估计 |
| 条件引入 | 49.6% | 54.9% | t4 +2.2%、t3 −2.3%，整体持平略偏 t4 |
| 通道相减（R−B>60 替代 HSV） | 85.2%（虚高） | 75.3%（虚高） | **证伪**：inner_density 判据不迁移，误锁箭头/基地灯 |
