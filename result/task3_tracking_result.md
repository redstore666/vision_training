## 叠加内容

- **R 标中心**：绿色（字形直接检出，`R (detected)`）或橙色（字形不可见、按已有估计外推，`R (estimated)`）圆点 + 圆圈。
- **被选目标**：黄色扇叶圆轮廓 + 十字圆心 + `ID n detected th=xxx°`（角度从右方起算、逆时针为正，与任务 2 定义一致）；丢失时红色圆圈 + `ID n LOST m`（m 为已丢失帧数），在预测位置保留身份。
- **两中心连线**：品红色直线连接 R 标中心与目标中心。
- **其他有效目标**（task_4 双目标场景）：青色圆圈 + 各自 `ID n`，标明同时存在但未被选中的有效目标。
- **无关结构**：灰色细圈（不参与锁定）。
- 左上角显示帧号、候选簇数量与当前点亮目标数；`binary_process.mp4` 展示掩膜、轮廓、候选簇与 R/目标标记。

## 检测方法

1. **掩膜**：能量机关发光为深橙红色，`H∈[0,17], S≥55, V≥80`（HSV 8 位）。基地灯偏黄（H≈16~31）、场边横幅偏绿（H≈95~115），均落在掩膜外；残余干扰靠形状特征排除。阈值由两个视频的色相直方图实测标定。
2. **目标簇**：双环靶标在掩膜中断成 2~4 段弧，把半径 ≥8px 的块按 48px 链式聚类；形状筛选：外接半径 ∈[15,95]、填充率 ≤0.55（排除灯带字母等实心块，其填充率 ≈0.9）、包围盒长宽比 ≤4、面积 ≤3200。
3. **点亮判别（核心特征）**：点亮靶标为"双环 + 中心标"结构，其 0.5R 内侧圆有显著掩膜能量（实测点亮目标 inner_density 中位数 0.24，未点亮单环 0.07）。判定采用**滞回**：`≥0.13` 进入点亮、`<0.09` 才退出，避免靶标动画造成状态闪烁；该值再做 0.8/0.2 的指数平滑。
4. **R 标中心**：R 字母是脉冲 LED（实测可见率约 30%~40%），其**形状签名**在两个视频上高度一致——半径 ≈12px、面积 ≈260px²、圆形度 0.33~0.62、填充率 0.42~0.75，且在同类尺寸块中孤立（流向圆点成串、环碎片圆形度过低）。以签名为观测，用**链式跟踪**累积命中的目标（链以"位置+速度+场景漂移"预测，允许长时间间隙）；命中最多的链即为 R。字形不可见时保持上一位置并随场景漂移外推，超过 90 帧无命中则标记丢失、不再外推（避免给出错误位置）。R 到点亮目标的距离上限 700px 用于剔除假链。
5. **场景漂移**：由位置池中各在场条目的速度取**逐分量中位数**估计（中位数抗旋转分量与个别异常污染），用于 R 外推与关联预测。

## 锁定、丢失与重选规则

- **身份管理**：维持"扇叶位置池"，每帧把候选簇按近邻关联到池条目（门限 55px + 条目速度外推），簇尺寸/形状不合格的块不参与。目标 ID 只在锁定/重选时分配，**绝不使用每帧轮廓列表顺序**；条目因长期缺席被删除、之后同一扇叶重新出现时**继承原 ID**（同一物理目标保持同一编号，避免 ID 无意义膨胀）。
- **初始锁定**：在点亮（含滞回）、稳定（最近 10 帧在场 ≥6 次）、持续点亮（最近 10 帧点亮 ≥4 次）、面积 ≥250px² 且入池 ≥10 帧的条目中，选面积最大者。
- **丢失容忍**：目标簇消失或熄灭时标记 `LOST`，保留身份并按条目速度外推等待恢复，容忍 **45 帧（1.5 s）**。
- **重选规则**（分配/继承 ID 并写入事件日志）：
  1. 当前目标连续 **15 帧（0.5 s）** 非点亮，且存在其他点亮且稳定的条目 → 判定为"击打后切换"，立即重选；
  2. 持续丢失超过 45 帧 → 释放身份，之后出现满足锁定条件的点亮条目即重选。
- **同时双目标（task_4）**：只有当前目标熄灭/丢失才可能切换；另一个点亮目标只标注为候选（青色 `ID n`），**不夺走已选身份**。

## 已知失败情况

1. **点亮/未点亮的边界情形**：个别未点亮扇叶的"六边形轮廓 + 竖条"结构与点亮双环的内侧密度接近，可能造成短暂误锁；随后会被点亮状态刷新或丢失容忍机制纠正。已通过提高进入阈值（0.10→0.13）并加入退出滞回（0.09）消除主要误锁。
2. **R 字形不可见时段**：R 为脉冲 LED，直接检出率 56%~60%，其余时间用外推估计；长时间（>90 帧）无命中会标记 `R (lost)` 并停止外推，等字形重现后自动恢复。task_3 开头（约 f150 前）风车尚未点亮、没有可用结构，R 处于 searching 状态。
3. **相机大幅平移/变焦**：task_3 末段（约 f630~790）相机快速平移且目标全部熄灭，期间以 searching/LOST 为主，事件日志中有相应记录。
4. **task_4 切换频繁**：大能量机关点亮目标按击打顺序转移，锁定选择 20 次；每次切换均由"当前目标熄灭 15 帧 + 存在其他点亮目标"触发，日志可逐条复核。若个别切换对应的是同一扇叶的短暂熄灭-重亮，编号会因继承机制保持不变。
5. **角度仅用于显示**：本任务不要求角速度拟合，`th` 为当前帧的相对角度显示值，不含预测。

## 复现方式

```bash
cd build
cmake --build . --target task3_windmill -j4
./task3_windmill ../resources/task_3.mp4   # 输出 ../result/task3_windmill/task_3/
./task3_windmill ../resources/task_4.mp4   # 输出 ../result/task3_windmill/task_4/
# 可选：--show 实时显示窗口，--debug 打印逐帧跟踪状态
```

注意：输出目录默认相对**当前工作目录**解析（`../result/task3_windmill/<视频名>`），因此请在 `build/` 目录下运行；也可显式指定输出目录作为第二个参数。
