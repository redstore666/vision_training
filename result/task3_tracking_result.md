## 叠加内容

- **R 标中心**：绿色圆点 + 圆圈（字形直接检测时标 `R (detected)`；字形不可见、按场景漂移外推时为橙色 `R (estimated)`）。
- **被选目标扇叶圆轮廓与中心**：黄色圆圈（外接圆）+ 十字中心，标注 `ID n detected`。
- **两中心连线**：品红色直线（R 标中心 → 目标中心），并显示目标相对 R 中心的角度 `th=xxx°`（从右方起算、逆时针为正，与讲义任务 2 的角度定义一致）。
- **目标 ID 与跟踪状态**：`detected`（有效观测）/ `LOST n`（丢失第 n 帧，红色，在预测位置保留身份）；画面左上角显示帧号、簇数与当前点亮目标数。
- 二值化过程视频展示 HSV 掩膜、轮廓、候选簇（灰圈）、R 标（绿/橙圈）与锁定目标（黄圈）。

## 检测方法

1. **掩膜**：能量机关发光为深橙红色，`H∈[0,17], S≥55, V≥80`（HSV 8 位）。基地灯偏黄（H≈16~31）、场边横幅偏绿（H≈95~115），均落在掩膜外；残余干扰靠形状与结构特征排除。所有阈值由两个视频的色相直方图实测标定。
2. **目标簇**：双环圆靶在掩膜中断成 2~4 段弧，将半径 ≥8px 的核心块按 48px 链式聚类；形状筛选：外接圆半径 ∈[15,95]、填充率 ≤0.55（排除灯带字母等实心块，实测填充率 ≈0.9）、包围盒长宽比 ≤4（排除流向圆点连成的细长条带簇）。
3. **点亮判别**：点亮靶标为"双环 + 中心标"结构，其 0.5R 内侧圆有显著掩膜能量（实测点亮目标 inner_density 中位数 0.24，未点亮单环 0.07）；`inner_density ≥ 0.13` 判为点亮。该特征是区分点亮/未点亮靶标的主要依据。
4. **R 标**：R 字母为脉冲 LED，实测字形可见率仅 28%~37%（task_3 最长连续不可见 85 帧，task_4 达 463 帧）。采用字形检测（半径 5~16、面积 60~450、圆形度 ≤0.82、孔洞 ≤1、未并入任何簇）+ EMA 跟踪；不可见时按场景漂移速度外推（R 相对风车静止，随相机整体运动）。初始化要求候选位置跨帧复现（12 帧内 ≥8 次）且被 ≥3 个可用簇在 ≥90° 角度范围内包围，防止误锁基地灯支架等孤立形状。R 估计位置 45px 内的块不参与聚类，防止 R 字母被流向圆点条带簇链式吸收。

## 锁定、丢失与重选规则

- **身份管理**：维持"扇叶位置池"，每帧将检测簇按近邻关联到池条目（门限 55px + 条目速度外推，速度 EMA 同时吸收相机平移）。目标 ID 只在锁定/重选时分配（自增编号），**绝不使用每帧轮廓列表顺序作为 ID**。
- **初始锁定**：点亮（inner≥0.13）、稳定（最近 10 帧在场 ≥6 次）、面积 ≥250 且入池 ≥10 帧的条目中选面积最大者。
- **丢失容忍**：当前目标簇消失或熄灭时标记 `LOST`，保留身份按条目速度外推等待恢复，容忍 **45 帧（1.5 s）**。
- **重选条件**（满足其一，分配新 ID 并记录事件）：
  1. 当前目标连续 **15 帧** 非点亮（熄灭），且存在其他点亮且稳定的条目 → 判定为"击打后切换"，立即重选；
  2. 持续丢失超过 45 帧 → 释放身份，之后一旦出现满足锁定条件的点亮条目即重选。
- 重选依据是"条目位置 + 点亮状态 + 稳定性"的跨帧关联，不是单帧轮廓匹配，因此不会因遮挡抖动而跳变。

## 已知失败情况

1. **熄灭判定依赖形状特征**：个别未点亮扇叶的"六边形轮廓 + 竖条"结构与点亮双环靶标的内侧密度接近，曾出现短暂误锁（几十帧量级），随后被点亮状态刷新或丢失容忍机制纠正。task_3 中段已通过提高点亮阈值（0.10→0.13）消除主要误锁。
2. **R 字形可见率低**：R 标为脉冲 LED，直接检出率仅 18%~42%；其余时间为外推估计。长时间（>150 帧）不可见时放弃估计并标 `R searching`，等字形重现后自动恢复。task_3 的 R 标直到 f479 才首次满足初始化条件（此前 R 字母过暗或不在画面）。
3. **相机快速平移段**：task_3 末段（约 f630~790）相机大幅平移且目标全部熄灭，期间以 searching/LOST 状态为主，事件日志中有对应的释放记录。
4. **task_4 切换频繁**：大能量机关点亮目标切换次数多（20 个 ID），其中绝大多数对应真实的点亮转移；若存在个别误切换，均已在事件日志中留痕，可结合 `track_log.csv` 复核。
